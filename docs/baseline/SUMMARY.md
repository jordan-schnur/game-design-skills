# Baseline pattern (8 of 9 scenarios in)
The model already reasons well about game design. Failures are SHAPE failures, not knowledge/discipline failures:
1. No persistent artifact: decisions, pillars, values, playtest findings are given in chat and lost. Nothing points at a game bible.
2. No output contract: pillar check / principle named / analogs / test design / confidence / record appear inconsistently (some in each answer, never all).
3. Weak experimental discipline: changes several variables at once; hypothesis rarely pre-stated; no explicit "what to observe".
4. Concept phase lacks the vision+pillars+non-goals artifact; jumps to engineering.
5. Bible entries invent rationale instead of asking / marking unknown.
6. Principles recalled with hedged attribution; the doc's precise sourced versions (Soren's formula) not surfaced.
=> Form: positive recipes / required slots (not prohibitions). Shared contract across phase skills + bible as memory + sourced catalog.
